# Isaías García

### Backend & Software Developer · PHP · Laravel · Vue · TypeScript

Desarrollador de software enfocado en el **diseño, arquitectura y construcción de sistemas web empresariales**.

Mi especialidad es el ecosistema **PHP/Laravel**, trabajando principalmente en backend, procesamiento asíncrono, integración de servicios, automatización de procesos y diseño de soluciones orientadas a mantener la **consistencia, escalabilidad y mantenibilidad** del sistema.

También desarrollo interfaces modernas utilizando **Vue 3, TypeScript, Inertia.js y Tailwind CSS**, buscando que frontend y backend formen una arquitectura coherente.

Me interesa especialmente resolver problemas donde la lógica de negocio, el procesamiento de datos y la confiabilidad del sistema son más importantes que simplemente construir una interfaz.

### Laravel Async Reporting Engine

Motor de generación de reportes orientado al procesamiento de grandes volúmenes de información.

**Enfoque técnico:**

* Procesamiento mediante Jobs y Queues.
* Separación entre generación, procesamiento y exportación.
* Manejo de grandes datasets.
* Procesamiento asíncrono para evitar bloquear las peticiones HTTP.
* Seguimiento del estado de generación de reportes.
* Diseño orientado a escalabilidad.

### Laravel Audit Trail

Sistema de auditoría para aplicaciones Laravel enfocado en la **integridad y trazabilidad de operaciones**.

**Enfoque técnico:**

* Registros de auditoría inmutables.
* Cadena de integridad mediante hashes SHA-256.
* Procesamiento asíncrono.
* Persistencia posterior al commit de transacciones.
* Registro de eventos y cambios relevantes.
* Verificación de integridad de la cadena de auditoría.
